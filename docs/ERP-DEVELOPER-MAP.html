1. Application Overview & Architecture

Textile ERP is a full-stack application for a textile business: inventory (rolls, pieces, remanents), point-of-sale, commissions, branch tasks, employee management, and audit history. The React SPA talks to an Express REST API backed by PostgreSQL via Prisma.

3. Authentication, Roles & Route Guards

Roles

RoleAccess Level
ADMINFull access; create/edit/delete employees; approve registrations; all sidebar sections
MANAGERSame route access as ADMIN; cannot create/edit/delete employees (ADMIN-only mutations)
EMPLOYEESection-scoped via allowedSections (server) or localStorage rules; always sees Task Employee
TRUSTEESame section scoping as EMPLOYEE

Route Guard Chain (App.tsx → ProtectedLayout)

  1. Not authenticated → redirect to /login

Inventory Item ID Format (QR)

Composite ID encoding branch + family code + sub-code + color + type + piece length. Parsed by lib/inventoryCodes.ts. Scanned on Sales, Inventory, Exchange, Item Conversion, Item Pricing, Item Input.

Branches

Codes: A, B, C, E, F (shop floors) and S (Storage). Defined in lib/inventoryCodes.ts as BRANCH_DESTINATIONS.

10. Section-to-Section Data Flow

Item Input ──POST /inventory──► Inventory DB ──GET /inventory──► Inventory View
                                    │
                                    ├──QR scan──► Sales (deduct stock via POST /sales)
                                    │                  │
                                    │                  ├──► EmployeeCommissionEntry
                                    │                  ├──► Daily/History Sales (GET /sales)
                                    │                  └──► BranchTaskEntry (cutting tasks)
                                    │
                                    ├──PATCH /inventory──► Item Conversion (transfer/cut)
                                    │
                                    └──GET /inventory/:id──► Exchange (POST /sales/exchange)

Plain Cloth Pricing ──GET plain-cloth──► Sales (Plain Cloth accordion)
Item Pricing ──PUT settings/prices──► Commission calculation on sales
Sales Commission ──PUT settings/rate──► Commission Payouts (GET /commissions/pending)

Sales ──AuditLog──► Activity History
Inventory mutations ──AuditLog──► Activity History
Employee CRUD ──AuditLog──► Activity History

Employee Accounts ──allowedSections──► Sidebar visibility per employee
